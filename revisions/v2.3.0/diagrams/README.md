# Standalone architecture

`runtime.png` and `ingestion.png` are exact renders of final PDF pages 8 and 17, respectively. They show the native diagrams, labels, trust/provider boundaries and connection controls. `architecture.mmd` is a logical flow specification using the same canonical component names and edges. Its subgraphs identify boundary membership; the PNGs preserve their precise nested visual placement. These are proposed designs, not a deployed or safety-certified system.
